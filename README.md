# K-RALLY 重制版（Symbian SISX 版《烈火战车》）

> **本作是 Symbian SISX 版本《烈火战车 / K-Rally》（Infinite Dreams，2006）的粉丝重制版。**
> 只复用了原作的**文本**（台词、车手名、赞助商名）；美术、音频、物理、赛道全部为程序化重写，未使用原作任何图像/音频素材。

从零实现的可玩重制：生涯模式、车库、商店、车辆升级、AI 战术层，Android 端 90 FPS。

> 仓库：https://github.com/dsglenn35-netizen/krally-remake
> 正式版：**v1.0.0** — https://github.com/dsglenn35-netizen/krally-remake/releases/tag/v1.0.0
> 许可：MIT（见 [LICENSE](LICENSE)）

## 运行

| 方式 | 命令 |
|---|---|
| 浏览器 | 直接打开 `index.html`（或 `python -m http.server` 后访问） |
| Android | 安装 `KRallyRemake.apk`（minSdk 24 / targetSdk 35） |

操作：WASD / 方向键 驾驶，SPACE 开火，SHIFT 弃武器，P 暂停，M 静音；手机端用屏幕虚拟按键（◀ ▶ / 刹车 / 油门 / 开火）。
暂停面板可切换**手感档位**：硬核 / 标准 / 轻松（轻松档带自动回正，会把车拉回赛道中线）。

性能：Android 端默认**硬件加速**，90Hz 屏实测 90 FPS；如需回退用 `--es hw 0` 启动。

## 玩法系统

### 生涯（CAREER）
三档锦标赛，逐级解锁：

| 赛事 | 场次 | 圈数 | AI 强度 | 冠军奖励 |
|---|---|---|---|---|
| ROOKIE CUP | 3 | 3 | 0.86 | $800 / 150 XP |
| CHAMPIONSHIP | 4 | 3 | 0.95 | $2500 / 400 XP |
| MASTER LEAGUE | 4 | 4 | 1.03 | $6000 / 900 XP |

每场按名次发奖金（1st $600 / 2nd $380 / 3rd $220 / 4th $120）+ XP。前一档完成才解锁下一档。

### 车库（GARAGE）
4 辆车，速度 / 加速 / 抓地三条属性，可切换当前用车，属性以进度条呈现。

### 商店（SHOP）
- **CARS**：KITE（初始）/ VIPER $2400 / WRAITH $6500 / NOVA-X $13000
- **UPGRADES**：ENGINE（速度 +16 / 加速 +12，3 级）、TIRES（抓地 +0.05/级）、
  WEAPONS（开局自带 ROCKET，等级=弹药）

### 存档
localStorage `krally_save_v2`：现金、XP、车辆、每车升级、锦标赛进度、最佳圈。


## 结算与观察

**名次变化曲线**：比赛每 0.5s 采样一次实时排名（最多 240 个样本），结算界面画出 4 条曲线 —— 横轴是时间，纵轴是名次（1 上 4 下），每条线用对应车手的主色，玩家线加粗。绘制前做 3 点中值平滑，避免并排换位导致的锯齿。

**对手车况卡**：点击左侧名次条的任意一行，弹出该车手信息 —— 头像、车型、当前圈数、速度、武器与弹药、剩余血量条。再点一次收起。


## 排位 / 幽灵 / 编辑器

**排位积分**：每场按名次结算（+25 / +12 / −8 / −20），段位分五档（青铜/白银/黄金/铂金/钻石，阈值 0/1100/1300/1500/1700），按车手独立保存；结算界面、车手卡、生涯车手条都会显示。

**幽灵车**：20Hz 记录玩家轨迹，单圈刷新最佳成绩时把该圈存为幽灵；同赛道重跑时半透明车按时间回放，HUD 显示当前幽灵成绩。

**赛道编辑器**：点选控制点画线，实时用正式赛道的样条预览，可调路宽与地貌，保存后进入赛道列表，可直接试跑。


### 开放赛道与检查点（v0.4.0）

编辑器可切换「闭合 / 开放」：开放赛道是单程冲刺，1 圈到终点即完赛，可设 0–6 个检查点，必须按顺序全部通过；烘焙地图上会画出检查点门。

### 幽灵多圈对比（v0.4.0）

幽灵按赛道保存最多 5 圈轨迹，HUD 同时显示最佳圈与平均圈，并实时给出与最佳圈的差值（±0.00s）。
